### 2.4 UI 层如何访问 Manager

```gdscript
# UI 层脚本示例（如 deck_list.gd）
extends Control

@onready var _deck_mgr: DeckManager = App.get_deck_manager()

func _ready():
    # 订阅变更信号
    _deck_mgr.entity_created.connect(_refresh_deck_list)
    _deck_mgr.entity_deleted.connect(_refresh_deck_list)
    # 加载初始数据
    _load_decks()

func _load_decks():
    var result = _deck_mgr.get_all_decks()
    if result.success:
        _render_decks(result.data as Array[DeckEntity])
```

### 2.6 各层节点归属规则速查

| 层级       | 继承自                  | 节点树归属                  | 生命周期                 |
| -------- | -------------------- | ---------------------- | -------------------- |
| **UI 层** | `Control` / `Node2D` | `root/Viewport` 下的场景实例 | 随场景切换创建/销毁           |
| **逻辑层**  | `Manager` → `Node`   | `App` 子节点              | 全局持久，应用启动到关闭         |
| **数据层**  | `DBManager` → `Node` | `App` 子节点              | 全局持久，数据库连接保持         |
| **实体层**  | `RefCounted`         | **不加入节点树**             | 由调用方持有引用，引用计数归零时释放   |
| **调度层**  | `RefCounted`         | **不加入节点树**             | 由 Manager 临时实例化，用完释放 |

### 2.7 UI 调试场景（Deck + Database CRUD）

已新增调试场景，方便直接在 Godot 中快速验证牌组与数据库的读写流程。

- 场景路径：`res://scenes/ui/debug_crud_panel.tscn`
- 根节点：`Control`
- 脚本路径：`res://scenes/ui/debug_crud_panel.gd`
- 主要能力：
  - 牌组 CRUD：创建、按 ID 查询、列出、重命名、删除
  - 数据库 CRUD（notes 表）：创建、按 ID 查询、更新、删除、列出最近 50 条
  - 底部日志面板：展示每次操作的结果码与错误信息

运行方式建议：在编辑器中直接打开该场景运行，或通过 `change_scene_to_file("res://scenes/ui/debug_crud_panel.tscn")` 跳转。
