# README 与 GitHub 同步

## 文档依据

README 的运行入口、维护分工与功能说明应以当前文件和最近的功能文档为准。会话内日期时间会重置，已保存的评分与到期时间会保留，两个行为应一起说明。

本地已安装的插件不等于仓库已经包含。通过 Git 跟踪状态区分核心依赖和本地可选工作流，避免首次获取仓库的使用者误以为 FMOD 与 Kanban 已随源码提供。

## 验证与提交

纯文档修改检查相对链接、目录和资源引用，不重复运行完整功能测试。既有回归结果明确标注来源，不作为本次重新执行的测试。

仅暂存本次 README 和经验记录，保留其他未提交工作。GitHub 推送以远端分支哈希核对结果；本地提交成功与网络推送成功分别报告。

## 网络排查

命令中写入 GitHub 原始 URL 仍可能被 Git 的 `url.*.insteadOf` 规则重写。连接失败时核对地址重写与代理，使用命令级设置检查直连，保留用户原来的全局配置。
