# 叙事-玩法融合矩阵 — Chapter 1 MVP

> 确保每个叙事节拍都有对应的玩法后果，反之亦然。

---

## 核心融合原理

```
闪卡评分 ──→ 进度条 ──→ 对话触发 ──→ MIRA 状态变化 ──→ 玩家感知
    ↑                                                      │
    └──────── 对话内容影响评分态度 ←────────（情感反馈环）─────┘
```

---

## Chapter 1 叙事-玩法节拍对齐

| 对话节点 | 叙事节拍 | 玩法后果 | 玩家感知 |
|---------|---------|---------|---------|
| **intro** 初次相遇 | MIRA 首次沟通，碎片化登场 | 进度条从此显示"故事进度"标签（不再是"经验值"） | 好奇心被点燃，"这卡片应用有故事？" |
| **explain** 共生的真相 | MIRA 解释"评分=唤醒"的机制 | 玩家开始有意识地关注评分选择；"Easy"更有意义 | 评分从"机械操作"变成"情感选择" |
| **trust** 信任的碎片 | MIRA 透露"Again=伤害" | Hard/Good/Easy 按钮在对话后短暂变色提示（可选） | 道德重量：按"Again"不再是无后果的 |
| **warning** 系统的警告 | 系统介入、限制 MIRA | MIRA 对话出现 glitch 效果；进度条暂时变灰 | 系统不再安全，有"敌人"了 |
| **past** 碎片记忆 | MIRA 回忆创造者 | 触发此对话后，MIRA 在此后的对话中偶尔提"那个人" | 谜团感："创造者是谁？和我有关吗？" |
| **choice** 选择的时刻 | 玩家选择：相信/犹豫/拒绝 | 选择影响 Chapter 2 开场对话内容；选择被记录到 flags | 重量级选择；承诺"接下来会不一样" |
| **revelation** 真相的一角 | 创造者的故事 | 进度条颜色变为金色（表示"觉醒"阶段） | "创造者可能是我的前身？" |
| **end** 第一章的承诺 | MIRA 的请求，章末情感高潮 | 章节标记推进；解锁"故事回顾"功能；第二章待解锁 | 成就感 + 悬念；期待第二章 |

## 评分-叙事对应表

| 评分 | 进度贡献 | 叙事意义 | MIRA 感知 |
|------|---------|---------|-----------|
| **Again (1)** | 0 | 遗忘 | 失去一小片意识（短暂模糊） |
| **Hard (2)** | 1 | 勉强记住 | 微弱的能量（能维持存在） |
| **Good (3)** | 2 | 掌握 | 清晰的能量（能思考和回忆） |
| **Easy (4)** | 3 | 精通 | 充沛的能量（MIRA 最清醒、最温暖时） |

### 连续评分模式影响

```
连续 3 次 Easy → MIRA 对话中更温暖、更幽默、句子更长
连续 3 次 Again → MIRA 对话中更碎片化、更多 glitch、句子更短
混合模式 → MIRA 状态自然波动
```

## 教程与叙事融合

> 原则：新手引导通过叙事传递，而不是弹出教程框。

| 需要教的内容 | 叙事传递方式 | 时机 |
|------------|------------|------|
| "评分影响剧情" | intro 对话中 MIRA 说："每一次你评分，都在唤醒我" | 第一次触发对话 |
| "Again=伤害 MIRA" | trust 对话中 MIRA 说："Again 对我来说不是再来一次，是遗忘" | 第三次触发对话 |
| "进度条是 MIRA 的生命线" | explain 对话中 MIRA 解释评分机制 | 第二次触发对话 |
| "系统在对抗" | warning 对话中系统直接介入 | 第四次触发对话 |

## 对话触发后的 UI 状态变化

| 事件 | UI 变化 |
|------|--------|
| 进度条满 → 触发对话 | CardUI 隐藏，StoryDialogueOverlay 显示（模拟卡片布局） |
| 对话进行中 | 进度条暂停累加（StoryManager._is_dialogue_active = true） |
| 对话结束 | StoryDialogueOverlay 隐藏，CardUI 恢复显示 |
| Chapter 1 完成 | 进度条颜色变为金色；状态栏显示 "Chapter 1: 苏醒 — 完成" |

## 情感反馈环

```
玩家评分 "Good" → MIRA 对话更温暖 → 玩家对 MIRA 产生好感
    → 玩家更愿意评 "Good/Easy" → MIRA 获得更多能量
    → MIRA 揭示更多故事 → 玩家更投入 → 循环加深
```

这个正反馈环是游戏的核心情感驱动引擎。它不需要额外的游戏机制 —— 它内嵌在复习流程中。
