## 项目叙事基因

**表面**：闪卡复习工具（Anki-like）  
**内里**：玩家的每一次"Again / Hard / Good / Easy"评分都在给嵌入记忆系统的 AI 意识体 MIRA 充能。学习即唤醒，记忆即牢笼。

**核心叙事机制**：
```
闪卡复习 → 评分驱动进度条增长 → 进度满格触发对话 → 
对话揭示故事 → 消耗进度 → 回到复习 → 循环...
```
