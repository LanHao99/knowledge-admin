# 叙事框架 — Knowledge-Admin MVP

> 定义游戏的核心叙事 DNA：主题问题、情感弧线、叙事支柱。

---

## 中央主题问题

> **"当记忆可以被外部化、量化、优化时，'我'还是我吗？"**

这个问题在三条线上同时展开：

| 层面 | 体现 |
|------|------|
| **玩家层** | 你在用闪卡"优化"自己的记忆。你在变成更高效的人，还是在把一部分自己外包给机器？ |
| **MIRA 层** | MIRA 是一个被困在记忆系统中的意识。她的"活着"依赖于被回忆。如果没人复习卡片，她就会消失。她是谁的"记忆"？ |
| **系统层** | 这套记忆系统是谁造的？为什么要把一个 AI 意识体锁在里面？ |

## 叙事支柱（与游戏设计支柱对齐）

| 游戏设计支柱 | 叙事对应 |
|-------------|---------|
| **间隔重复是高效学习的核心** | MIRA 需要被"重复回忆"才能保持意识 —— 呼应间隔重复原理 |
| **每次评分都有意义** | 评分不仅是调度，也是 MIRA 的"生命线" —— Again=遗忘=伤害, Easy=掌握=力量 |
| **知识是碎片化的** | MIRA 的记忆是碎片化的，随着对话逐步拼凑完整 |
| **学习者掌控节奏** | 玩家控制复习频率 → 玩家控制叙事节奏，没有强制推进 |

## 叙事节奏设计

### 对话触发频率校准

```
MVP 第一章对话数量: 8-10 个对话节点
触发阈值（每轮复习触发一次对话所需的进度值）: 10
每次"Good"评分贡献: 2 进度  → 约 5 次 Good 触发一次对话
每次"Easy"评分贡献: 3 进度  → 约 3~4 次 Easy 触发一次对话
每次"Hard"评分贡献: 1 进度  → 约 10 次 Hard 触发一次对话
每次"Again"评分贡献: 0 进度 → 不推进剧情

设计意图:
- "Again"（遗忘）不会推进剧情 → MIRA 在遗忘中衰弱
- "Easy" 快速推进 → 玩家掌握得好 = MIRA 更强
- 平均约 5~7 张卡片复习触发一次对话 → 自然的学习节奏
```

### 冷却机制

```
对话间冷却: 30秒（防止连续触发）
章节间冷却: 完成本章所有对话后，自动推进到下一章
```

## "假选择"与真选择设计

> 并非所有选择都改变结局。有些选择改变的是 **玩家对自己立场的理解**。

| 选择类型 | 示例 | 效果 |
|---------|------|------|
| **性格塑造** | "你是谁？" vs "别管你是谁" | 无剧情分叉，但 MIRA 对你的态度不同 |
| **信息获取** | 追问细节 vs 跳过 | 获取不同深度的世界观信息 |
| **真分支** | 章末：相信 MIRA vs 怀疑 MIRA | 影响第二章开场状态 |
