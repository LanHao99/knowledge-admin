# 编辑器 2D 预览残留处理

## 问题

2026-10-15，Godot 4.7.2 编辑器正在编辑 `res://content/scenes/desktop/boot_screen.tscn`，画布却显示旧的知识管理主页。现场检查发现，编辑器的预览 SubViewport 同时包含当前 `BootScreen` 和额外的可见 `MainMenu` 同级节点。导致额外实例遗留的具体操作尚未确定。

## 处理

将非当前场景的 `MainMenu` 从编辑器预览父节点移出，保留实例及其编辑数据。不修改业务场景、节点可见属性或启动图片设置。临时诊断插件处理完成后禁用并移除。

## 验证

实际编辑器截图确认旧主页消失，画布显示当前启动场景。切换到 `main_menu.tscn` 后，再返回 `boot_screen.tscn`；两次预览父节点均只有一个场景子节点，未再出现叠加。由于此次仅处理编辑器会话状态，没有保留运行时代码或设置变更，采用现场切换及截图验证。
