# 剧情进程释放回归

## 问题与原因

手动关闭已经释放窗口，但剧情自然结束和停止测试仍经 `App._on_overlay_finished()` 调用 `WindowManager.end_dialogue(true)`，该分支原本将未知程序最小化并复用。后续剧情继续使用损伤为 0.7 的同一实例，因此仍有裂纹。

## 修正行为

剧情自然结束和停止测试都释放未知程序，清理注册表及任务栏，恢复学习现场与弹窗。下一次剧情连接创建无损新实例。手动最小化保持原进程和裂纹。完全破碎仍等待快照完成后释放，不提前销毁捕获对象。

## 验证结果

Godot 4.7.2，独立工程及独立存档，Forward+／D3D12。

| 验证 | 结果 |
| --- | --- |
| 修改前的新增生命周期回归 | 失败；旧实例、任务栏仍存在，下段损伤值仍为 0.7 |
| 修改后的剧情动作 GUT | 9/9，95 条断言 |
| 实际剧情与画面检查 | 54/54 |
| 剧情测试台与学习现场回归 | 265/265 |

实际依次播放系统警告的局部破损分支、自然读完本段、跳转后续剧情，检查旧实例弱引用失效、新实例损伤为零且裂纹层隐藏，并检查 [后续剧情实际截图](story_reconnected_without_cracks.png)。还检查停止测试释放正文、延迟自动推进不会访问旧正文、手动最小化仍保留裂纹、手动关闭及完整碎裂的释放行为。

机器可读结果：[剧情动作](process_cleanup_verification.json)、[剧情测试台](process_cleanup_story_regression.json)。原桌面验收中的后台复用断言已同步改为进程释放及新连接；此次未重跑整套桌面应用导航。

## 既有测试限制

完整 GUT 为 103 项中 96 项通过、7 项失败。失败仍来自工作区的 `my_computer.tscn` 已移除脚本访问的 `%InfoLabel`；此问题在前次修改前已经复现，详见 [前次回归记录](followup_validation.md)。本次保留该场景改动，未把完整回归记为通过。

运行有本机证书存储读取错误和 FMOD 实时调试端口占用提示；上述定向测试与两组 GPU 检查的断言和退出状态通过，没有本次功能的脚本错误。
