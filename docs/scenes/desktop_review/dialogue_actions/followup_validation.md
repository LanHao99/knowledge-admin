# 壁纸选项与窗口关闭回归

## 行为

控制面板只显示「无壁纸」及已解锁图片。山景和塔楼在未解锁时没有列表项；收到山景后即时加入，当前选择与预览按资源路径保留，塔楼继续隐藏。

未知程序在剧情结束或最小化时仍保留当前实例与裂纹；待机时点击关闭则释放进程，移除任务栏入口。重新打开和后续剧情创建完好的窗口，损伤不跨进程保存。

## 验证

Godot 4.7.2、Forward+／D3D12，使用独立工程与独立存档。

| 检查 | 结果 |
| --- | --- |
| 剧情动作 GUT | 8/8，84 条断言 |
| 壁纸设置 GUT | 9/9，62 条断言 |
| 实际剧情与画面检查 | 48/48 |

GPU 检查包含实际鼠标点击关闭、旧实例释放、最小化保留损伤、重新打开无裂纹，以及解锁前后列表的真实显示。结果见 [GPU 报告](followup_verification.json)，[未解锁图片隐藏截图](wallpaper_choices_locked_hidden.png)。
